# Dorpn Website

Official website documentation portal for the **[Dorpn](https://github.com/Dorpn-hub/Dorpn)** programming language.

## Overview

This repository contains the source code for the official Dorpn website. It serves as the central documentation hub, syntax reference, and resource center for developers learning and using the Dorpn language.

## Project Structure

```text
Dorpn-Website/
├── css/          # Stylesheets and custom UI designs
├── js/           # Interactive scripts and client-side logic
├── docs/         # Documentation pages and syntax references
├── index.html    # Main landing page
└── README.md     # Project documentation
```

## Features
-  **Language Documentation**: Comprehensive syntax guides and usage examples.
- **Responsive Design**: Optimized for viewing across mobile, tablet, and desktop devices.
- **Fast Performance**: Lightweight static pages for quick load times.

## Tech Stack
 * HTML5 / CSS3 / JavaScript
 * GitHub Pages (Hosting)
